# Proposta: Envio de Código de Verificação por E-mail (5 Dígitos)

## Contexto
Para aumentar a segurança após o login ou cadastro na NightFall, é necessário adicionar uma etapa de verificação de e-mail através do envio de um código numérico aleatório de 5 dígitos.

## Objetivo
Gerar e enviar um código de 5 números aleatórios para o e-mail do usuário após a etapa inicial de login/cadastro, exigindo a confirmação do código para liberar o acesso ou concluir a conta.

## Escopo
- Geração de código aleatório de 5 dígitos no backend/estado.
- Simulação ou envio do código para o e-mail informado.
- Tela ou etapa de confirmação de código de 5 dígitos.
