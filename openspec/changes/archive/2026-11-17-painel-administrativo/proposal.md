# Proposta: Painel Administrativo Completo

## Visão Geral
Implementação do Painel Administrativo (`/admin`) no e-commerce NightFall para gestão centralizada de produtos (CRUD), visualização de pedidos de clientes e controle da base de usuários.

## Objetivos
1. Criar a rota `/admin` e o componente visual `admin_page`.
2. Implementar `AdminState` para controle de abas e gerenciamento de estado.
3. Permitir adicionar novos produtos ao catálogo em tempo real.
4. Permitir remover produtos do catálogo.
5. Listagem de pedidos e clientes cadastrados.
