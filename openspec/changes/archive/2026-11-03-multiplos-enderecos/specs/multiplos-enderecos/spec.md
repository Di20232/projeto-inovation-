# Spec: Múltiplos Endereços e Seleção de Principal

## Requisitos
- O usuário pode visualizar todos os seus endereços cadastrados na aba Endereços do perfil.
- O usuário pode abrir um formulário para cadastrar um novo endereço (Título, CEP, Logradouro, Número, Complemento, Bairro, Cidade, Estado).
- O primeiro endereço cadastrado é definido automaticamente como principal.
- O usuário pode alternar qual endereço é o principal a qualquer momento.
- O usuário pode remover endereços cadastrados.
