# Spec: Painel Administrativo

## Requirements
- O login com `admin@admin.com` e senha `admin123` concede privilégios administrativos (`is_admin = True`).
- A página `/perfil` exibe a aba "Gerenciar Site" apenas para administradores autenticados.
- O painel administrativo permite adicionar novos produtos, editar preço, nome, descrição, categoria e marca, e excluir produtos.
