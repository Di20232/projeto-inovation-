# Especificação: Página de Perfil do Usuário

## Requisitos
1. **Visualização de Dados**: O usuário logado deve poder visualizar seu nome e e-mail cadastrados.
2. **Atualização de Cadastro**: O usuário deve poder alterar seu nome de exibição com feedback visual.
3. **Proteção de Acesso**: Acessar `/perfil` sem estar autenticado deve exibir uma tela de aviso solicitando login.
4. **Navegação Rápida**: O nome do usuário exibido no cabeçalho deve funcionar como link direto para `/perfil`.
