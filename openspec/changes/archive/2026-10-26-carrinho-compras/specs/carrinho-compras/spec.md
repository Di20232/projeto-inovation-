# Especificação: Carrinho de Compras

## Requisitos
1. **Adição de Produtos**: O usuário deve poder adicionar produtos ao carrinho a partir da modal de detalhes do produto.
2. **Controle de Quantidade**: O carrinho deve permitir incrementar ou decrementar a quantidade de cada item, removendo automaticamente o item caso a quantidade chegue a zero.
3. **Cálculo de Subtotal**: O carrinho deve calcular e exibir o subtotal atualizado com base nos preços e quantidades.
4. **Indicador Visual**: O cabeçalho deve exibir o ícone do carrinho com um badge reativo mostrando a quantidade total de itens.
5. **Drawer Lateral**: O carrinho deve ser exibido em um painel lateral deslizante acessível a qualquer momento.
