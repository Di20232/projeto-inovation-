# Spec: Edição de produto

## Requisitos
- Cada produto listado no painel tem um botão "Editar" que abre um modal com os dados atuais.
- Salvar com preço inválido, campos obrigatórios vazios ou nome de outro produto mostra erro e não altera nada.
- Salvar com dados válidos atualiza o produto na loja, no filtro de marcas e no carrinho.
