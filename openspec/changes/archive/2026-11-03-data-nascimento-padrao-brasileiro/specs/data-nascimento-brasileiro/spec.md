# Spec: Data de Nascimento no Padrão Brasileiro

## Requisitos
- O campo de data de nascimento deve exibir o placeholder `DD/MM/YYYY`.
- O valor digitado deve ser formatado automaticamente no padrão brasileiro `DD/MM/YYYY` (dia/mês/ano).
- A formatação deve ser aplicada tanto na tela de cadastro (`/cadastro`) quanto na tela de perfil (`/perfil` - Meus Dados).
