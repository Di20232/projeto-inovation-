# Proposta: Pedidos reais no painel

## Contexto
A aba "Pedidos" do `/admin` mostrava um único pedido escrito no código.

## Objetivo
O administrador ver todos os pedidos salvos.

## Escopo
- Listar número, cliente, data, itens, total e situação, do mais recente para o mais antigo.
- Entregar a lista só a administradores.

## Fora do escopo
- Aba "Clientes", que continua com texto fixo.
- Pedidos feitos em outros computadores ou guardados apenas no Xano.
- Alterar situação de pedido.
