# Especificação: Atualização de Schemas de Banco de Dados

## Requisitos
1. **Persistência de CPF e Data de Nascimento**: A tabela `USER` e o endpoint `auth/signup` devem aceitar e persistir os campos `cpf` e `birth_date`.
2. **Estrutura de Endereços**: A tabela `endereço` deve conter todos os campos necessários para armazenar endereços completos por usuário.
